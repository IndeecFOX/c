# c2
C2 (Си ту>Си то>Сито). Скрипт анализирующий DNS запросы, затем сверяющий их с листами и в случае отсутствия в них - проверяющий через cheburcheck доступен ли домен. Если нет - в список обхода добавить. Если в вайтлисте - обновить список вайтлиста. Доступен - не проверять неделю повторно. Параметры настраиваемые.

Keenetic/NC:
```bash
curl -O https://raw.githubusercontent.com/IndeecFOX/c/2/install && sh install
```
С ТГ:

Скрипт анализирующий DNS запросы, затем сверяющий их с листами и в случае отсутствия в них - проверяющий через curl и при необходиомости через cheburcheck доступен ли домен. Если нет - добавляет в кастомные домены. Если в вайтлисте - обновить список вайтлиста. Доступен - не проверять 10 дн. повторно. Параметры настраиваемые.
OWRT: Нужны минимальные правки по путям, мб инит.д. на системд какой переписать для автостарта.
При открытии какого-то сайта может насрать доменами и часть может проверяться секунд 10 если нет в листах и curl не получил 34кб (стучит в чебурчек тогда), из-за чего внесение в TCP_custom с последующим открытием может быть с задержкой. Зато внесёт все домены))
